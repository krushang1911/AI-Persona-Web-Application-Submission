## 🌟 The Concept

**Panel** is a unique, single-file frontend web application that revolutionizes how you get career advice. Instead of asking one AI and getting a generic response, Panel takes your single career-related question and routes it through **six unique professional personas**. 

Whether you're deciding on a major, prepping for an interview, or negotiating a salary, you'll get a 360-degree view of your situation instantly.

---

## ✨ Standout Features

- 🧠 **Bring Your Own AI**: Connects natively to **OpenAI** or **Google Gemini** models directly from the browser.
- 🎓 **Demo Mode**: Built-in simulated responses for seamless classroom demos and presentations—no API key required!
- 👤 **Hyper-Personalization**: Fill out your profile (education, skills, goals) and watch the AI tailor its advice specifically to *you*.
- 🤝 **Consensus Engine**: Automatically analyzes all six answers and highlights where the experts agree, saving you time.
- 🎨 **Premium Aesthetics**: A stunning, responsive UI featuring smooth micro-animations, beautiful typography, and seamless Dark/Light mode transitions.

## 🚀 Quick Start Guide

No `npm install`. No build steps. Just pure web technology.

1. **Clone or Download** this repository.
2. **Double-click** `index.html` to open it in any modern web browser.
3. **Open Settings** (click the ⚙️ gear icon in the bottom left sidebar).
4. **Choose Your Experience**:
   - 🎓 **Demo Mode**: Toggle on to instantly test the UI with pre-written, simulated responses.
   - ⚡ **Live AI Mode**: Select OpenAI or Gemini, paste your API key, type your preferred model (e.g., `gpt-4o-mini`), and start asking real questions!

> ⚠️ **Note on Security**: In Live AI Mode, your API key is stored locally in your browser and sent directly to the AI provider. This is perfect for local testing and demos, but should not be deployed to a public server without a backend proxy.
